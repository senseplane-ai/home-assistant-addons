# Senseplane add-ons for Home Assistant

Eyes and ears for your AI agents. The **Senseplane** add-on sends the Home Assistant
sensors you choose, and your IP cameras, to a Senseplane server, paired with a code.

## Install

1. In Home Assistant, open **Settings → Apps → App store** (older versions:
   **Settings → Add-ons → Add-on store**), then **⋮ → Repositories**.
2. Add `https://github.com/senseplane-ai/home-assistant-addons`.
3. Install **Senseplane**, set your server, start it, and enter the code it shows in your
   Senseplane console.

This repository is published from
[`integrations/home-assistant-addon`](https://github.com/senseplane-ai/senseplane/tree/main/integrations/home-assistant-addon)
in the main Senseplane repository; change it there. Apache-2.0.
